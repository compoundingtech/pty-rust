# Lane E — WP-CONF conformance harness and the first CLI files, against the Node pty

Read lane-common.md first, then plan-verify-libs.md section "B1" in full. Worktree name: `laneE`. Branch: `laneE`.

You own: `crates/pty-conformance/**` (Cargo.toml, src/harness.rs, src/lib.rs, tests/*.rs, fixtures/**),
`scripts/conformance-map.rs` (or a `cargo xtask`-style bin inside the crate), `docs/conformance.md`.
Deps: pty-core (protocol + registry paths), pty-testkit (Session::spawn to run the CLI inside a real tty),
serde_json, regex, tempfile, libc.

The point of this lane: the suite must be GREEN AGAINST THE NODE PTY first. Run everything with
`PTY_TEST_BIN=$(which pty) cargo test -p pty-conformance` (the Node pty, 0.12.0+500eab2). Then run it against
the Rust binary (`PTY_TEST_BIN=$PWD/target/debug/pty` after `cargo build -p pty`) and report which tests fail —
red is expected there; do not weaken a test to make Rust pass.

1. `src/harness.rs` — `Rig`: temp `PTY_ROOT` under `/tmp/pc-XXXXXX` (short paths), `PTY_ROOT_LEGACY_SILENT=1`,
   env scrub (`PTY_SESSION`, `PTY_SESSION_GENERATION`, `PTY_SESSION_DIR`, `PTY_REAP_ON_EXIT`, `PTY_SERVER_CONFIG`,
   `ST_AGENT`, `ST_ROOT`, `NO_COLOR`), `TERM=xterm-256color`, `HOME` = a temp home (so `~` and the default root are
   deterministic), PATH preserved. `rig.pty(&[..]) -> Out{status, stdout: Vec<u8>, stderr: Vec<u8>}` with a 30 s
   timeout; `pty_env(extra, args)`; `pty_stdin(bytes, args)`; `pty_tty(args, rows, cols) -> pty_testkit::Session`
   (runs the CLI inside a real PTY for attach/peek -f/prompts); `rig.daemon(id, cmd: &[&str], DaemonOpts{
   no_display_name, tags, ephemeral, env, unset_env, isolate_env, cwd, keep}) -> Daemon` via `pty run -d --id ...`,
   waiting ≤ 30 s for `<id>.sock` and `<id>.json`; `Daemon::{socket_path, meta() -> serde_json::Value, pid()}`;
   `rig.connect(id) -> Conn` (raw socket client on pty_core::protocol: `attach(rows, cols)`, `peek(plain, full)`,
   `resize`, `data`, `detach`, `status`, `next_packet(timeout)`, `collect_until_exit(timeout)`, `sequence()`);
   `rig.is_node()/is_rust()` from `pty --version` (`-rust` marker); deadline polls (10 s default, `PC_SLOW=1`
   doubles); `Drop` SIGTERMs every pid in `<root>/*.pid`, waits 2 s, SIGKILLs. Binary selection: `PTY_TEST_BIN`
   absolute path; unset → `target/<profile>/pty` of this workspace (resolve from `CARGO_MANIFEST_DIR/../../target`).
   Assertion helpers: `expect_status`, `stdout_str`, `expect_contains`, `expect_regex`, `expect_json`, `expect_lines`.
